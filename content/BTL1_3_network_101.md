# Security Fundamentals; Network 101

#### Network Fundamentals

- **TCP**; Transmission Control Protocol
	- connection-oriented protocol
	- allows two systems to establish a connection that will enable the two-way transmission of data
	- **data loss is detected and automatically corrected** ➡️ Hence, **reliable**
	- Three way handshake (SYN, SYN-ACK, ACK)
- **UDP**; User Datagram Protocol
	- allows datagram to sent without connections in IP-based networks
	- connectionless ➡️ specify the target port
- **ICMP**; Internet Control Message Protocol
	- internet layer protocol used by network devices to diagnose network communication issues
	- **used to determine whether or not data is reaching its intended destination in a timely manner**
